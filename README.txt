# Mritunjay Sharma Interior Work — Home Page

## Files
- `index.html` — complete Home page structure
- `style.css` — main styles and theme
- `responsive.css` — tablet/mobile layouts
- `js/custom.js` — Owl Carousel, portfolio filters, FAQ/contact form helpers
- `images/` — the logo and five supplied interior images

## Run in VS Code
1. Extract this folder.
2. Open the folder in VS Code.
3. Install/use the Live Server extension if you have it.
4. Right-click `index.html` → **Open with Live Server**.

Internet is needed to load Bootstrap, Font Awesome, Owl Carousel, jQuery and Google Fonts from their CDNs.

## Notes
- The contact form prepares an email using the visitor's email app; it does not store or send messages through a server yet.
- The gallery uses the supplied inspiration images. Replace them with actual completed projects when you have them.
- The testimonial cards contain sample brand statements, not actual customer reviews. Replace these with genuine customer feedback before publishing.
- Check the address and contact details once before launch.
